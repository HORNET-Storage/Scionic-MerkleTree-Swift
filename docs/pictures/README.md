# The Pictures of the README

The README has three pictures. They are the ones in the README of the Go library, byte for byte:

| Picture | File |
| --- | --- |
| Comparison of Many Merklized Forms | [`merklized-forms.png`](merklized-forms.png) |
| Scionic Merkle Tree | [`scionic-merkle-tree.png`](scionic-merkle-tree.png) |

One program draws all three, so they share one theme and one example tree. It is in the Go library's repository, under [`docs/pictures`](https://github.com/HORNET-Storage/Scionic-Merkle-Tree/tree/main/docs/pictures), where a README says how to draw them again and how to change what they say.

A picture is changed there, and the three files are copied here. Nothing in this folder is edited by hand.
